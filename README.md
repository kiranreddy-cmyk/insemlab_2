# Even or Odd Number Checker (React Conditional Rendering)

A simple React project created to demonstrate the core concept of **Conditional Rendering** using React functional components.

## Objective
To check whether a given number is **Even** or **Odd** using JavaScript's modulus operator (`%`) and React's conditional rendering with the ternary operator (`? :`).

## Features
- **Functional Component**: Implemented using a beginner-friendly React functional component (`App`).
- **Initial State**: Variable `number` initialized to `7`.
- **Conditional Rendering**: Uses ternary operator `number % 2 === 0 ? "Even Number" : "Odd Number"`.
- **Dynamic User Input**: Simple input field to test any number dynamically.
- **Pure CSS**: Styled using clean, basic CSS without any frameworks (no Bootstrap, no Tailwind).
- **Clear Student-level Lab UI**: Displays heading, input field, entered number, and a separate result box.

## How to Run the Project

1. Install dependencies (already installed):
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open your browser at the URL shown in the terminal (usually `http://localhost:5173`).
